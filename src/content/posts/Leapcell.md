作者以「能否替代 Cloud Run / Vercel」为切入点，对主打「永久免费、GitHub 一键部署」的云容器平台 Leapcell 做了一次完整实测，结论是部署体验优秀但国内访问是硬伤，目前更适合作为备用部署工具。

### 🎯 主打卖点

官方宣传的核心优势包括永久免费无套路、深度集成 GitHub 的一键部署、基于容器的轻量可移植、快速部署与弹性扩展，以及共享宿主机内核带来的高资源利用率。

### 🔬 实测过程

作者先用自己基于 Astro 的博客仓库测试：Leapcell 原生识别 Astro 项目并自动填好构建参数，约两分钟完成部署，仪表盘信息清晰。但官网与默认域名在中国区域全部无法访问，必须借助代理才能打开；绑定自定义域名后问题依旧，与 Vercel「绑定域名即可正常访问」的差距明显。

### ⚖️ 值得与短板

值得肯定的是真免费、部署体验对新手友好、日常维护成本低；短板则是国内无加速节点，且缺少边缘缓存、国内 CDN、Serverless 函数等进阶功能。作者据此给出的建议是：面向海外或学习类项目可用，面向国内用户、需要高可用的生产环境仍应选择更贴合国内网络的平台。

## 前言

作为一个常年折腾云部署的开发者，我的收藏夹里躺着一堆 "免费部署平台" 的链接，大多是点开看一眼就吃灰。但前几天刷到 Leapcell，号称 "**Cloud Run / Vercel 完美替代品**"，还把 "永久免费" 写在脸上——这牛吹得有点大，我倒想看看它有几分真本事。

于是拿我的博客（Astro 写的，正好是个标准测试品）实测了一整套流程：注册、部署、绑域名、测速。下面是全记录，先说结论：**部署体验确实不错，但国内访问是硬伤，替代 Vercel 这事，目前没戏。**

## 一、官方宣传的核心卖点（先看看它怎么吹）

动手之前，先把官网的宣传点列出来，后面实测一个个验：

- **永久免费无套路**：不用试用、不用升级，写明 "永久免费"。
- **GitHub 一键部署**：关联仓库就能上线，号称不用碰服务器。
- **轻量可移植**：容器化打包，到处能跑。
- **快速部署与弹性扩展**：启动快，还能弹性伸缩。
- **高效资源利用**：容器共享内核，资源利用率高。

听起来很美，对吧？行，实测见真章。

## 二、实测过程：从访问到部署的全记录

### 1. 初始访问：先吃了个闭门羹

兴冲冲打开 Leapcell 官网（[https://leapcell.io](https://leapcell.io)），结果页面转半天加载不出来。ping 了一下，好家伙，**在中国区域全军覆没**——得开 "魔法上网" 才能打开。

这就很有意思了：一个号称要替代 Vercel 的平台，第一步就把国内用户挡在门外。而 Vercel 绑定域名后国内裸连基本没问题。这一分，Leapcell 先丢了。

![官网截图](/images/Screenshot%202025-10-03%20at%2019-01-53%20Leapcell%20Ship%20All%20Your%20Code%20Online%201.webp)
### 2. 项目部署：这一步确实香

"魔法" 加持下打开官网，界面倒是挺清爽。注册登录后进 "创建服务"，我直接选了博客的 GitHub 仓库（Astro 项目）。

这里要夸一句：Leapcell **原生识别 Astro**，构建命令、输出目录全自动填好，点一下 Deploy 就完事。对不熟悉部署细节的人来说，这种 "无脑操作" 是真的友好。

部署日志一路绿灯，进度条实时更新，**约 2 分钟**搞定。单看部署体验，确实对得起宣传。
![部署页面截图](/images/Screenshot%202025-10-03%20at%2019-06-11%20Create%20Service%20Leapcell.webp)
### 3. 部署完成：仪表盘不错，但有个老问题

部署成功自动跳到服务仪表盘：服务状态、部署记录、访问统计一目了然，管理起来挺省心。点它给的默认域名（xxx.leapcell.app），在 "魔法" 状态下加载飞快，博客一切正常。

但把 "魔法" 一关——又打不开了。我又测了国内多线路，结果如下：国内访问基本指望不上。跟 Vercel（国内延迟 100-200ms 能裸连）一比，差距肉眼可见。

### 4. 绑自定义域名：操作简单，但治标不治本

想着实际用肯定得绑自己的域名，我把 [lenmei.eu.org](https://lenmei.eu.org) 接了上去。流程很顺：域名管理里按提示加 DNS 记录，等 10 分钟左右解析生效。

但结果在意料之中——"魔法" 下访问飞快，无 "魔法" 依然打不开。**绑域名只解决了 "好不好看"，没解决 "能不能打开"**。对比 Vercel 绑完域名国内就能裸连，Leapcell 这 "替代品" 的名号，实在担不起。
![绑定域名截图](/images/Screenshot%202025-10-03%20at%2019-15-09%20lenmei.eu.org%20-%20Domain%20Leapcell%201.webp)
## 三、我的结论：部署体验 8 分，国内访问 0 分

实话实说，Leapcell 不是一无是处：

- **免费是真免费**，没藏着掖着，拿来跑个小博客、作品集挺合适；
- **部署是真省心**，GitHub 一关联、框架自动识别，新手也能两分钟上线；
- **仪表盘是真清晰**，状态、日志、统计一目了然。

但短板也是真致命：**国内访问基本等于没有**。对面向国内用户的项目来说，这一条就判了死刑。再加上缺少边缘缓存、国内 CDN、Serverless 函数这些进阶能力，复杂项目也指望不上它。

所以我的建议很直接：

- **可以玩**：海外项目、纯学习折腾、不需要国内访问的静态站；
- **别指望**：国内用户为主的项目、生产环境、要上 Serverless 的复杂应用。

## 结语

折腾一圈下来，Leapcell 给我的感觉就是个 "偏科生"：部署体验这科接近满分，国内访问这科直接交白卷。它现在更适合当个**备用部署工具**——比如 Vercel 抽风的时候有个地方能顶一下。

至于 "替代 Vercel"？等它哪天有了国内节点再说吧。在那之前，该用啥还是用啥。
